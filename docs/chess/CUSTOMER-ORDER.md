- 提交身份：匿名

表单字段：

1. 收货人姓名，必填
2. 联系电话，必填
3. 收货地址，必填
4. 付款备注 / 微信支付单号后 6 位，必填
5. 购买留言，选填

网页不能自动确认微信支付是否到账。收到记录后，需要在微信账单中按付款备注或交易单号后 6 位核对，再安排发货。

顾客信息仅用于核款、联系和配送。不要把订单表导出后提交到公开 GitHub 仓库。
